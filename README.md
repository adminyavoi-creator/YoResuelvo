# YoResuelvo!
Tú lo necesitas. Alguien lo resuelve. Plataforma regional de descubrimiento, comparación y contratación de servicios.

## Estado real
Fundación del proyecto y demo local, no aplicación productiva completa. No hay cuentas reales, backend conectado, técnicos verificados ni contrataciones reales. Oficia Delicias se consultó como referencia arquitectónica, sin copiar su aplicación de espacios.

## Ejecutar
Node 20+: `npm test`. Para abrir la demo: `npm start` y visita http://localhost:4173. No necesita dependencias externas. El servidor incluido es exclusivamente local.

## Entregables
- docs/PLAN_DESARROLLO.md: producto, fases y criterios de salida.
- docs/IDENTIDAD.md: identidad institucional propuesta.
- docs/ARQUITECTURA.md: diseño Supabase, permisos y despliegue Vercel.
- docs/BACKLOG.md: trabajo pendiente priorizado.
- public/: demo adaptable con búsqueda, comparación de hasta tres perfiles y tickets locales imprimibles.

Los ejemplos son ficticios. Los tickets demo se guardan en el navegador; no incluyen datos personales ni se sincronizan. El ticket es registro de servicio, no factura ni comprobante de pago.
